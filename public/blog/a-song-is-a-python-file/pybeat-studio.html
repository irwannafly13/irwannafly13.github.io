        How playback works
        
The player reads BPM, PATTERNS, CHORDS, ARRANGEMENT and the hits(...) lines from your code, and edits take effect on the next step while it plays. The browser has its own versions of the instruments, so changes inside a def body only change the sound when you run the file with Python.
